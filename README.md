## 换之前核这五件事，少走一次退款流程

第一件，IP 类型到底是不是你要的。把拿到的 IP 丢进 ipinfo、ping0 这类库查 AS 归属，写的是家庭宽带运营商才算住宅IP，写 IDC 就是数据中心 IP。平台认的是这个归属，不是商家页面上的形容词。

第二件，退款窗口多长，退的是现金还是余额。丽萨是 48 小时，真家宽 VDS 只退余额；搬瓦工新账户 30 天。666Clouds 的退款政策和支付方式，我这轮翻的公开资料里没有可核实的说明，下单前自己在官网条款和结算页确认一遍，别默认它跟谁一样。

第三件，能不能切机房。搬瓦工能，丽萨不能，666Clouds 按机房分套餐卖。地区选错就是重买，这条对做本地业务的人影响最大。

第四件，线路是不是大陆优化。名字里带 9929、CN2 GIA、CU4837 的一般有优化，写“国际带宽”“原生IP”没说线路的，多半是普通国际出口，国内直连要用中转。

第五件，续费价和计费周期。促销价常常只对首期有效，年付摊到每月好看，但一次性掏的钱多，试错成本也高。

## 常见问题

### 做 TikTok 一定要住宅IP 吗

做账号运营和直播，住宅IP 基本是标配。数据中心的 IP 在平台数据库里有明确标记，账号权重和流量表现通常不如住宅 IP。只是刷视频、看内容，什么 IP 都行。

### 换了商家，IP 会不会变脏

会，任何一家都可能。IP 段是循环使用的，上一任用户干过什么你不知道。所以不管买哪家，开通当天先用 ipinfo、ping0、abuseipdb 查一遍风险评分，把解锁能力一起测完，别等用了半个月才发现问题。

### 48 小时退款够不够测

够，但你得当天就动手。机器开通后立刻测 IP 纯净度、目标平台解锁、国内方向延迟和晚高峰速度，四项测完不满意马上开工单。拖到第二天晚上再测，很多商家已经开始算计费周期了。

### 便宜的年付能不能长期用

能，但别把年付当省钱的第一选择。年付锁的是价格，也锁了你在这家待一年。第一次用某家，先月付跑一个月，确认线路和 IP 稳定，再考虑年付。丽萨那年付 449.1 元、折 37.4 元/月看着便宜，600GB 流量和 50Mbps 带宽够不够你用，得先跑过才知道。
